# ArtThumb 1.2.0

Initial public release by **Cao Le**.

## Highlights

- Native Windows Explorer thumbnails for PSD, PSB, AI, EPS, INDD, and PDF.
- Application icon badge in the bottom-right corner without duplicate Explorer overlays.
- Correct InDesign XMP page previews and improved Illustrator PDF-compatible rendering.
- ArtThumb Settings with a live preview, adjustable badge size, and thumbnail sharpness.
- Manual GitHub update checks; no background service, polling, telemetry, or automatic download.

## Install

1. Download `ArtThumb-1.2.0-windows-x64.zip`.
2. Extract the complete ZIP.
3. Run `ArtThumbSetup.exe` on 64-bit Windows 10 or Windows 11.

The installer works per user and does not require administrator rights.
